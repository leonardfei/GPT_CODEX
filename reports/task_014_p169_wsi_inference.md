# Task 014 — P169.svs WSI inference to QuPath GeoJSON

## Status and interpretation boundary

COMPLETED on 2026-09-30. P169 has no reference labels in this task, so no independent P169 accuracy, F1, AUROC, AUPRC, or sensitivity can be estimated. All counts and class proportions below are model outputs, not verified biological composition. P84 provides a descriptive comparison only.

## Inputs and reproducible recipe

- Input: `/data/lf_data/he_image/P169.svs`; Aperio, 39,168 × 23,296 level-0 px, 6 pyramid levels, objective 20×, MPP-X = MPP-Y = 0.276812 μm/px from OpenSlide metadata.
- Detector: CellViT++ SAM-H x40 AMP checkpoint `/data/lf_data/CellViT-plus-plus/checkpoints/CellViT-SAM-H-x40-AMP.pth`. Binary nucleus detection/segmentation only, nominal 0.25 MPP network resolution (the CellViT implementation uses native 0.276812 target patch MPP), 1024 px patches with 64 px overlap, batch size 8, built-in overlap cleaning. The old PanNuke labels are not used for final typing.
- Classifier: Task012 single full-data Midnight checkpoint `/data/lf_data/result/final_model/midnight_fov12_finalblock_7class.pth`, SHA256 `ddb3d21f9492032b5f0509c5dc28de15a29b0074105991c5cd1168055d84f633` verified before inference. No ensemble.
- Each level-0 centroid receives a 12 μm × 12 μm physical crop bicubic-resampled to 57 × 57 RGB, then the exact Task012 224 × 224 bicubic resize, mean/std 0.5 normalization, CLS-plus-mean-patch embedding, and seven-class head. No class thresholds or other scientific design changes.

The Task013 reusable script was used with the new shared-output behavior provided by the upstream task specification. Its current source is `scripts/python/task013_predict_svs_geojson.py`; the server copy is `/data/lf_data/result/task014_p169_wsi_inference/task013_predict_svs_geojson.py`.

Detector command (executed separately, with its output reused by the wrapper):

```bash
/data/lf_data/task010_env/bin/python /data/lf_data/CellViT-plus-plus/cellvit/detect_cells.py \
  --model /data/lf_data/CellViT-plus-plus/checkpoints/CellViT-SAM-H-x40-AMP.pth \
  --binary --gpu 0 --resolution 0.25 --batch_size 8 \
  --outdir /data/lf_data/result/task014_p169_wsi_inference/detector \
  process_wsi --wsi_path /data/lf_data/he_image/P169.svs
```

Classifier/export command:

```bash
/data/lf_data/task010_env/bin/python /data/lf_data/result/task014_p169_wsi_inference/task013_predict_svs_geojson.py \
  --svs /data/lf_data/he_image/P169.svs \
  --output-dir /data/lf_data/HCC_result \
  --work-dir /data/lf_data/result/task014_p169_wsi_inference
```

Environment: `/data/lf_data/task010_env/bin/python` (Python 3.10.14, PyTorch 2.7.1+cu128, Transformers 4.45.2, NumPy 1.23.5, OpenSlide Python 1.3.1, OpenCV 4.5.4-dev, Ray 2.9.3), NVIDIA RTX PRO 5000 72GB Blackwell GPUs. This is deterministic inference; no random seed applies. Independent spatial QC uses seed 20260930 for a thumbnail point sample. Logs and detector intermediates remain under `/data/lf_data/result/task014_p169_wsi_inference`, not in the shared GeoJSON directory.

## Observed results, QC, and P84 descriptive comparison

CellViT detected **153,892** nuclei after standard overlap cleaning; Midnight classified exactly **153,892**. The detector JSON contains only `Background`/`Cell` typing. Its available binary-detection `type_prob` had mean 0.9450 and 10th percentile 0.8390; the centroid range was x = 2,614–36,365 and y = 2,314–21,240 level-0 pixels.

These differences are descriptive predictions, not tests of biological abundance or domain shift. Both slides are Tumor-dominant in the model output (P169 72.1%, P84 70.9%) and predict very few Neutrophils (P169 0.112%, P84 0.080%). The P169 versus P84 comparison was generated by `scripts/python/task014_compare_predictions.py` from the two task QC JSON files and is saved as `results/task014_p169_vs_p84_predicted_proportions.csv`. Similar extreme predictions on two slides do not validate either classifier or detector; they warrant targeted reference-label and QuPath visual review.

P169 maximum seven-class probability: mean 0.5837, 10th percentile 0.2705, median 0.5707, 90th percentile 0.9144. All per-cell probability vectors were finite and normalized before export; no confidence-based filtering was used. P84's mean maximum probability was 0.5511, a descriptive difference of +0.0327 for P169.

The exporter parsed and checked both P169 GeoJSON files. Independent `scripts/python/task013_verify_outputs.py` validation then confirmed 153,892 polygons and 153,892 centroids; exact seven-class count agreement; required names/RGB colors and CellViT-style QuPath `Feature` structures; all rings closed; all geometry within P169 level-0 bounds; and each centroid within its paired contour bounding box. The seeded 20,000-point thumbnail overlay in `figures/task014/P169_spatial_qc_overlay.png` was visually reviewed: detections followed tissue rather than blank background. This establishes broad spatial alignment, not microscopic segmentation accuracy or actual QuPath UI loading. The machine-readable checks are in `qc/task014/`.

The CellViT command took approximately 2 min 41 s (13:23:57–13:26:38 server time); the classifier wrapper, including checkpoint/hash checks and built-in GeoJSON QC, took 737.4 s (12 min 17 s). Logs are `/data/lf_data/result/task014_p169_wsi_inference/logs/detector.log` and `pipeline.log`. The independent QC ran afterward.
